- **Outfit** and **Space Grotesk** fonts (`app/src/main/res/font/`) — Google Fonts, SIL Open Font License 1.1. Static weight instances were generated from the upstream variable fonts using `fonttools`.
- **Material Symbols** icons (`app/src/main/res/drawable/ic_*.xml`) — Google, Apache License 2.0. Converted from the outlined SVG set to Android vector drawables.

No other third-party assets are bundled in this app.
